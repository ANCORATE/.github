## 🏢 About ANCORATE

**ANCORATE** is an independent software organization focused on developing security-oriented, privacy-conscious, and reliable software.

We aim to create practical solutions that give users greater control over their data while maintaining high standards of security, transparency, and usability.

Our projects explore different aspects of software security, encryption, and data protection.

We believe that secure software should not be a privilege. It should be accessible to everyone.

---

## 🎯 Our Mission

Our mission is to build software that makes digital security more accessible, understandable, and practical.

We focus on:

- Protecting sensitive information.
- Improving digital privacy.
- Developing reliable encryption solutions.
- Promoting transparency through open-source development.
- Encouraging responsible security practices.
- Giving users control over their digital environment.

## 🔍 Security

Security is an essential part of our development process.

We encourage responsible vulnerability disclosure and security-conscious contributions.

If you discover a potential security vulnerability:

1. Do not publicly disclose exploitable details.
2. Contact us privately.
3. Include a clear description of the issue.
4. Provide steps to reproduce the issue where appropriate.

**📧 Security Contact:** [ancorate@web.de](mailto:ancorate@web.de)

Please note that security features and guarantees depend on the individual project.
